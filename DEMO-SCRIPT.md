# DEMO SCRIPT — TriageLens (<5 minutes, target ~3:30)

Record on a real Jira Cloud site with the app installed and 3 sample issues.
Speak in English (submission materials must be in English). Show the app working
early — judges are not required to watch beyond 5 minutes.

## 0:00–0:25 — Problem (screen: Jira backlog, many issues)
"Dev teams drown in backlogs. Which issue matters most? Who is overloaded?
What is blocking what? The context is scattered across issues, comments and goals."

## 0:25–1:20 — Issue panel (screen: open PROJ-101)
- Open the TriageLens panel on a Critical issue.
- Point at the score (e.g. 76/100 Critical) and the itemised breakdown.
- "Every point is explained — no black box."
- Show linked goals + least-loaded teammate.
- Click "Apply suggested priority" and "Add labels" — show them applied on the issue.

## 1:20–2:20 — Rovo agent (screen: Rovo chat)
- Ask: "What should I work on first?" — agent calls triage-brief, answers with
  score, band and reasons.
- Ask: "Who is involved in PROJ-101?" — agent lists assignee, reporter, commenters.
- Ask: "Who on my team has room for more work?" — agent shows team load, lightest first.

## 2:20–2:50 — MCP (screen: Rovo Studio / third-party client)
- Show the TriageLens MCP tool `get-issue-triage` listed as a connected-app tool.
- Call it once from a custom agent; show the same score coming back.

## 2:50–3:30 — Close (screen: repo + Devpost page)
- "TriageLens: one Forge app, three surfaces — panel, Rovo agent, MCP.
  Deterministic scoring, Teamwork Graph context, zero external services."
- Repo: https://github.com/Shanumameyra/triagelens
- Category: Apps for Software Teams. Bonus: Best Agents · Best MCP · Best Teamwork Graph.
